# BTC / ETH 实时交易监测

手机和电脑都能打开的静态页面，跟踪 **BTC-USDT** 与 **ETH-USDT** 永续合约。

页面地址（Pages 开启后）：<https://donglee1021.github.io/crypto-dashboard/>

全部界面为简体中文，时间为欧洲/维也纳。信号由固定规则计算，**只供参考，不构成投资建议，也不给出仓位或杠杆**。

## 页面上有什么

- OKX 实时价格（公共 WebSocket，断线后改用 REST）
- 1 小时 / 4 小时 / 日线 K 线，叠加 EMA20、EMA50、EMA200 和布林带，副图为 MACD、RSI、KDJ
- 每个币、每个周期的规则分数和因子说明，以及 ATR 止损参考价
- 每个币、每个周期的支撑 S1–S3 和阻力 R1–R3（摆动点、枢轴、成交密集、整数关口），图上画横线；跌破或突破后给出下一档和测量移动 / ATR 参考价
- 每个币单独的入场结论：可以做多、可以做空或暂不入场。要趋势、触发、位置三项一起成立，并给出失效位、下一目标和盈亏比
- 每个币的见底/见顶可能性：未见底、可能在筑底、底部信号较强、底部已确认，以及对称的见顶结论。这是估计，不是定论
- 清算：多头/空头被强平的金额（1 小时、4 小时、24 小时）、较大的几笔，以及按杠杆档估算的清算区。估算区会标成估计
- 资金费率：当期、预测、距下次结算、年化、8 小时历史，以及多头和空头每 8 小时、每天占名义本金的持有成本
- 资金费率、持仓量、多空人数比
- 恐惧贪婪指数、标普 500、纳斯达克、美元指数、美债 10 年收益率
- 最近约 30 条新闻，标成利多 / 利空 / 中性；10 分钟内的条目会高亮

## 多久更新

| 数据 | 来源 | 间隔 |
| --- | --- | --- |
| 最新价 | 浏览器连接 OKX WebSocket | 实时；断开后每 10 秒轮询 |
| K 线与指标 | 浏览器请求 OKX | 约 60 秒 |
| 资金费率、USDT 永续持仓 | 浏览器请求 OKX | 约 3 分钟 |
| 多空人数比、全市场持仓 24 小时变化 | GitHub Actions 写入 `data/derivatives.json` | 每 10 分钟，且仅在内容变化时提交 |
| 新闻、恐惧贪婪、美股宏观 | Actions 写入 `data/news.json`、`data/macro.json` | 同上 |

OKX 的多空比和持仓历史接口不给浏览器跨域许可，所以由定时任务代抓。计划任务有时会晚几分钟。页面大约每分钟重新读取这些 JSON，并带上缓存清除参数。

综合分 = 1 小时×0.2 + 4 小时×0.3 + 日线×0.5 + 情绪调整（最多 ±3）+ 近 12 小时新闻净倾向（最多 ±2）。≥6 强烈做多，≥3 做多，≤−3 做空，≤−6 强烈做空，其余观望。

## 本地预览

```bash
python3 scripts/fetch_news.py
python3 -m http.server 8765
```

然后打开 <http://127.0.0.1:8765/> 。不要直接双击 HTML，否则浏览器会拦截本地文件的数据请求。

## 若 Pages 没有自动打开

仓库所有者打开：

**Settings → Pages → Build and deployment → Source → GitHub Actions**

保存后再运行 Actions 里的「部署 GitHub Pages」。

若定时任务提交失败并提示权限不足：

**Settings → Actions → General → Workflow permissions → Read and write permissions**

保存后重新运行「刷新新闻与宏观」。
